## How to view

### Option 1: GitHub Pages (recommended)
Enable GitHub Pages in repository Settings → Pages → Source: `main` branch. Your portfolio will be live at `https://{your-username}.github.io/{repo-name}/`.

### Option 2: Local preview
```bash
git clone https://github.com/{your-username}/{repo-name}.git
cd {repo-name}
open index.html
```

### Option 3: Markdown preview
Markdown files render natively on GitHub. Click any `.mdx` file to read it in your browser. Mermaid diagrams render automatically on GitHub.
